Print Settings

🖨️ Epson L3252 — Manual Two-Sided Printing

This printer does not use an automatic duplex unit. The system prints the front sheets first, then waits for you to re-feed the same sheets before printing the backs.

Re-feed / flip method

After the front print finishes, flip the sheet stack over the long edge (top-to-bottom) without changing left/right order, then reload it into the rear paper feed.

Use this only if your physical re-feed requires a left-to-right flip. The system will mirror the back layout accordingly.

Print mode
Epson L3252 workflow
  1. Print FRONT pages.
  2. Wait for the ink to dry, then collect the same sheets in order.
  3. Flip the stack using the selected edge and reload it in the Epson rear paper feed.
  4. The system automatically prints BACK pages using the matching mirrored positions.

Important: test with one A4 sheet first. Epson recommends testing manual two-sided printing before the full job.
